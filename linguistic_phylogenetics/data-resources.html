G Data Resources

This appendix describes the main databases used in linguistic phylogenetics and in the comparative study of language and culture. For each resource we describe what it contains, how it is organized, how it has been used in phylogenetic work, and where to find it. Many of these resources are now published in the Cross-Linguistic Data Formats (CLDF) (Forkel et al. 2018) and archived in versioned releases on Zenodo, which makes them easy to load with the tools described in Chapter 17 and Appendix F. Most of the databases that follow the CLDF model have a web interface built with the clld toolkit, usually at an address of the form https://<name>.clld.org, and a GitHub repository with the CLDF data. Two general points apply throughout. First, always cite the specific version of a database that was used, since databases are corrected and extended between releases. Second, read the documentation on how the data were collected and coded; every database embodies decisions (which concepts, which sources, which coding conventions) that affect what it can and cannot be used for (Chapters 3 and 15).

G.1 Language catalogues and classification

G.1.1 Glottolog

Glottolog (Hammarström et al. 2024) is a comprehensive catalogue of the world’s languages, dialects and language families. Each languoid (a language, dialect or family) has a stable identifier, the Glottocode (for example stan1293 for Standard English), together with its position in a genealogical classification, geographic coordinates, macro-area, endangerment status and an extensive bibliography of descriptive sources. Glottolog’s classification is deliberately conservative: it recognizes only families whose unity has been demonstrated by the comparative method, and lists a large number of isolates and unclassified languages. This makes it a reliable scaffold, but means that its trees are mostly unresolved at higher levels and have no branch lengths.

Glottocodes have become the standard identifier for linking linguistic datasets: Lexibank, Grambank, WALS (via mappings), PHOIBLE, D-PLACE and many others use them, so data from different sources can be joined by Glottocode (Chapter 17). Glottolog’s classification trees are distributed in Newick format and through its CLDF dataset (https://github.com/glottolog/glottolog-cldf), and are often used as topologies in global comparative analyses, with branch lengths assigned by rule (Chapter 13). Glottolog is published in numbered versions; analyses should cite the version used.

G.1.2 Other catalogues

Ethnologue is a commercial catalogue of the world’s languages with information on speaker numbers, vitality and location, identified by ISO 639-3 codes. Its classification is less conservative than Glottolog’s, and access to much of its data requires a subscription. ISO 639-3 codes, which Ethnologue maintains on behalf of the International Organization for Standardization, remain widely used and are mapped to Glottocodes by Glottolog.

G.2 Lexical databases

G.2.1 ASJP

The Automated Similarity Judgment Program (ASJP) database (Wichmann et al. 2022) contains short word lists for a 40-item subset of the Swadesh list, transcribed in a simplified phonetic alphabet (ASJPcode) for several thousand languages and dialects. The 40 items were chosen for their stability and their usefulness for classification (Holman et al. 2008). Because every list uses the same concepts and transcription, ASJP is the largest uniform lexical dataset available. It has been used for automated classification based on normalized Levenshtein distances (Brown et al. 2008), for dating language families with a calibrated distance-based method (Holman et al. 2011), and for global phylogenies based on automatically inferred cognates (Jäger 2018). ASJP lists do not contain cognate judgments; cognacy must be inferred (Chapter 3).

G.2.2 Lexibank

Lexibank (List, Forkel, Greenhill, et al. 2022) is a public repository of standardized word lists. It aggregates more than a hundred published datasets, each converted to CLDF by a reproducible script, with concepts linked to Concepticon, languages linked to Glottolog, and transcriptions standardized and segmented according to the CLTS reference catalogue. Many datasets include expert cognate judgments; others contain only word forms, for which Lexibank provides automatically computed features. Lexibank datasets are hosted on GitHub (https://github.com/lexibank) and archived on Zenodo, and include CLDF versions of several of the datasets described below (for example the ABVD and datasets used in published Sino-Tibetan and other phylogenies). Lexibank is the natural starting point for any new lexical phylogenetic analysis (Chapter 17).

G.2.3 Indo-European: IELex, IE-CoR and related databases

IELex (the Indo-European Lexical Cognacy Database) was assembled by Michael Dunn and collaborators, building on the Swadesh-list data of Dyen et al. (1992), and was used, with modifications, in several influential Bayesian analyses of Indo-European, including Bouckaert et al. (2012) and Chang et al. (2015). Its cognate judgments and meaning definitions were criticized and revised over time.

IE-CoR (Indo-European Cognate Relationships) (Heggarty et al. 2023) is a newer database designed to address these problems. It covers about 160 Indo-European languages, including ancient languages, for a list of 170 meanings, with explicit protocols for selecting the word for each meaning, for coding cognacy (including loanwords and parallel semantic shifts), and for documenting sources. It was developed from the earlier CoBL (Cognates in Basic Lexicon) project and underlies the analysis of Heggarty et al. (2023). Website: https://iecor.clld.org.

The data of Ringe et al. (2002), which code lexical, phonological and morphological characters for 24 Indo-European languages, remain an important resource for character-based analyses of Indo-European, and were used in comparisons of phylogenetic methods (Nakhleh, Warnow, et al. 2005).

G.2.4 Austronesian Basic Vocabulary Database (ABVD)

The ABVD (Greenhill et al. 2008) contains word lists for 210 basic meanings for well over a thousand Austronesian language varieties, with cognate judgments for a large subset. It underlies many of the best-known phylogenetic studies of Austronesian, including Gray et al. (2009), and has been used extensively as a scaffold for studies of cultural evolution in the Pacific (Chapter 14). The ABVD is available online (https://abvd.clld.org) and in CLDF through Lexibank. Sister databases built with the same software have been set up for some other families.

G.2.5 Bantu

Several lexical datasets underlie phylogenetic work on Bantu. The lexicostatistical study of Bastin et al. (1999) compiled basic vocabulary for several hundred Bantu languages, and has been reused in later work. Grollemund et al. (2015) assembled 100-meaning word lists with cognate judgments for over 400 Bantu and related languages, which were also used by Koile et al. (2022). The Bantu Lexical Reconstructions (BLR) database at the Royal Museum for Central Africa in Tervuren collects reconstructed Proto-Bantu roots, and is a resource for cognate identification. Several Bantu datasets are available in CLDF through Lexibank.

G.2.6 Sino-Tibetan

The Sino-Tibetan Etymological Dictionary and Thesaurus (STEDT) project at Berkeley (Matisoff 2015) compiled a large database of lexical forms from several hundred Sino-Tibetan varieties, organized by etymological sets, and published a reconstruction of Proto-Tibeto-Burman. Website: https://stedt.berkeley.edu. The datasets of Sagart et al. (2019) and Zhang et al. (2019), which include cognate judgments for basic vocabulary, are available in CLDF.

G.2.7 Uralic: UraLex

UraLex is a basic-vocabulary dataset for the Uralic languages, with cognate judgments and documentation of sources, compiled to support phylogenetic analyses of the family (Syrjänen et al. 2013). It has been used to examine how the choice of meaning list affects inferred Uralic trees, and as the basis of dated analyses (Honkola et al. 2013).

G.2.8 Australia: Chirila

Chirila (Contemporary and Historical Resources for the Indigenous Languages of Australia) (Bowern 2016) is a large database of lexical data for Australian Aboriginal languages, compiled from published and archival sources. It underlies phylogenetic studies of Pama-Nyungan (Bowern and Atkinson 2012; Bouckaert et al. 2018) and studies of lexical change in Australian languages. Website: https://doi.org/10.60600/YU/XHPJXB.

G.2.9 NorthEuraLex

NorthEuraLex (Dellert et al. 2020) contains word lists for over 1,000 concepts for more than a hundred languages of northern Eurasia, from Uralic, Indo-European, Turkic, Mongolic, Tungusic and other families, all in a uniform phonetic transcription. Its long concept list makes it useful for automated cognate detection, studies of sound correspondences, and comparisons across many families. Website: http://northeuralex.org.

G.2.10 Intercontinental Dictionary Series and World Loanword Database

The Intercontinental Dictionary Series (IDS) (Key and Comrie 2015) provides word lists for a standard list of roughly 1,300 concepts for several hundred languages, compiled from dictionaries. The World Loanword Database (WOLD) (Haspelmath and Tadmor 2009b) gives, for 41 languages from around the world, the vocabulary for a list of about 1,460 meanings together with expert judgments of whether each word is a loan, from which source, and how certain the judgment is. A companion handbook summarizes the findings (Haspelmath and Tadmor 2009a). WOLD’s “borrowability” scores for meanings are relevant to choosing meaning lists for phylogenetic analysis, and its loanword data can be used to validate borrowing detection methods (Chapter 8). Websites: https://ids.clld.org and https://wold.clld.org.

G.2.11 Other lexical resources

The Sound Comparisons project (https://soundcomparisons.com) provides recorded audio and transcriptions of comparable word lists for dialects and languages of several families, useful for studies of phonetic variation and dialect continua. The DiACL database (Carling et al. 2018) (Diachronic Atlas of Comparative Linguistics) combines lexical cognate data and typological data for several language families, including Indo-European, with good coverage of ancient languages; it has been used in phylogenetic studies of grammatical change. The CLDF datasets accompanying many recent phylogenetic papers, such as those for Dravidian (Kolipakam et al. 2018) and Tupi-Guarani, are often available through Lexibank or from the authors’ repositories.

G.3 Concepts, polysemy and sounds

G.3.1 Concepticon

Concepticon (List et al. 2016) links the concept lists used in linguistics (Swadesh lists, Leipzig-Jakarta list, ASJP list, questionnaires and the concept lists of individual datasets) to a common set of concept sets with stable identifiers and definitions. Linking a dataset’s concepts to Concepticon makes it possible to combine datasets with different concept lists, to see which concepts are shared, and to compare the stability or borrowability of concepts across studies. Website: https://concepticon.clld.org.

G.3.2 CLICS

The Database of Cross-Linguistic Colexifications (CLICS) (List, Greenhill, et al. 2018; Rzymski et al. 2020) records cases in which a single word expresses two concepts (for example ‘tree’ and ‘wood’, or ‘arm’ and ‘hand’) across thousands of language varieties, aggregated from Lexibank datasets. Colexification networks reveal semantic associations and are relevant to modeling semantic change and to understanding why some cognate sets shift meaning. Website: https://clics.clld.org.

G.3.3 CLTS

The Cross-Linguistic Transcription Systems (CLTS) reference catalogue (Anderson et al. 2018) defines a standardized set of speech sounds with phonetic feature descriptions, and maps the transcription conventions of many datasets and databases (including PHOIBLE) to it. It underlies the standardization of transcriptions in Lexibank, which makes automated alignment and sound-correspondence analysis possible across datasets. Website: https://clts.clld.org.

G.3.4 PHOIBLE

PHOIBLE (Moran and McCloy 2019) is a database of phoneme inventories for more than two thousand languages, compiled from multiple sources (some languages have several inventories from different descriptions), with features for each segment. It is used in typological studies of sound systems and in phylogenetic comparative studies of phonological evolution (Chapters 12 and 13). Website: https://phoible.org.

G.4 Structural (typological) databases

G.4.1 WALS

The World Atlas of Language Structures (WALS) (Dryer and Haspelmath 2013) contains data on about 190 phonological, grammatical and lexical features for about 2,600 languages, each feature compiled by a specialist and documented in a chapter. WALS was the first large typological database freely available online, and has been used in a great many comparative studies, including early phylogenetic tests of word-order correlations and studies of the stability of features (Dediu 2011; Wichmann and Holman 2009b). Its main limitation for phylogenetic work is its sparsity: most languages are coded for only a minority of features, and different features are coded for different language samples. Website: https://wals.info.

G.4.2 Grambank

Grambank (Skirgård et al. 2023) codes about 195 grammatical features for more than 2,400 languages, with a design that addresses the main limitations of WALS: features are mostly binary, defined with detailed coding instructions, and coded for every language in the sample from the same reference grammars, so that coverage is much more complete. It was compiled by a large team using a common questionnaire and is published in CLDF. Grambank is now the standard resource for phylogenetic comparative studies of grammar and for global analyses of structural diversity (Chapter 13). Website: https://grambank.clld.org; data: https://github.com/grambank/grambank.

G.4.3 AUTOTYP

AUTOTYP (Bickel et al. 2022) is a typological database built on the principle of autotypologizing: categories are defined bottom-up from the data rather than imposed in advance, and complex phenomena are coded as many fine-grained variables. It covers several thousand languages for some variables, with particular depth in morphology, alignment and clause linkage, and includes a genealogical and areal classification. Data: https://github.com/autotyp/autotyp-data.

G.4.4 Other structural resources

The Atlas of Pidgin and Creole Language Structures (APiCS) (Michaelis et al. 2013) provides comparable structural data for 76 pidgin and creole languages, relevant to questions about contact languages and their place in (or outside) family trees (Chapter 8). Website: https://apics-online.info. Areal and family-specific structural databases, such as the South American Indigenous Language Structures database, and family-specific questionnaires used in studies such as Dunn et al. (2005), complement the global databases.

G.5 Cultural, environmental and historical data

G.5.1 D-PLACE

D-PLACE (Database of Places, Language, Culture and Environment) (Kirby et al. 2016) links cultural data on about 1,400 societies, drawn principally from the Ethnographic Atlas (Murdock 1967) and other ethnographic datasets, to their languages (via Glottocodes), locations and environmental variables such as climate and ecology. Crucially for phylogenetic work, D-PLACE also collects published language phylogenies, so that cultural traits can be analyzed on a tree with the matching societies. It is the main data source for phylogenetic studies of cultural evolution (Chapter 14). Website: https://d-place.org; data: https://github.com/D-PLACE/dplace-cldf.

G.5.2 Pulotu

Pulotu (Watts, Sheehan, et al. 2015) is a database of supernatural beliefs and practices, together with social and environmental variables, for over one hundred Austronesian cultures, coded from ethnographic sources with careful attention to the historical period described. It was designed for phylogenetic analysis on Austronesian language trees and underlies studies of the coevolution of religion and political complexity (Watts, Greenhill, et al. 2015; Watts et al. 2016). It is now distributed in CLDF.

G.5.3 Seshat

Seshat: Global History Databank (Turchin et al. 2015) codes social complexity, warfare, religion, agriculture and many other variables for hundreds of historical polities, sampled through time from the Neolithic onward. It is used to study the dynamics of social complexity through time rather than across a tree, but can be combined with language trees for regions where polities are linked to languages. Website: https://seshatdatabank.info.

G.5.4 Kinbank

Kinbank (Passmore et al. 2023) is a global database of kinship terminology, recording the terms used for a standard set of kin relationships in more than a thousand languages, linked to Glottolog. It enables phylogenetic studies of the evolution of kinship systems, one of the classic topics of cultural phylogenetics (Chapter 14).

G.5.5 Genes and languages

The GeLaTo database (Genes and Languages Together) (Barbieri et al. 2022) pairs human population-genetic data with linguistic information for the same populations, and has been used to quantify how often genetic and linguistic histories match. Such resources are essential for formal joint models of genetic and linguistic history (Chapters 14 and 18).

G.6 Published trees

Phylogenetic comparative studies need trees, preferably full posterior samples rather than single summary trees. Several sources collect published language phylogenies:

  • D-PLACE includes a collection of published language phylogenies (with posterior samples where available), matched to the societies in its cultural datasets.
  • Phlorest, a collection of language phylogenies standardized in CLDF format by the CLDF team (https://github.com/phlorest), aims to make published trees uniformly accessible.
  • Glottolog provides classification trees for every family, without branch lengths, which can be combined into a global tree.
  • Global lexical trees have been inferred from ASJP data (Jäger 2018) and are available from the authors’ repositories.
  • Supplementary data of individual papers, often deposited in Dryad, Zenodo, OSF or GitHub, remain the main source for many trees. Authors who deposit their full posterior tree samples, input files and data make their work far more useful to others (Chapter 17).

G.7 Data formats

The Cross-Linguistic Data Formats (CLDF) (Forkel et al. 2018) are the standard format for most of the resources in this appendix. A CLDF dataset consists of CSV tables (languages, parameters, forms, cognates, values, codes, and others) and a JSON metadata file that describes them, following the W3C recommendation for CSV on the web. Specifications and validation tools are documented at https://cldf.clld.org. Chapter 17 shows how to read CLDF data into R, and Appendix F lists the Python tools (pycldf, cldfbench, pylexibank) used to create and validate CLDF datasets. NEXUS, PHYLIP and Newick (Chapter 2) remain the formats for exchanging matrices and trees with phylogenetic software.
