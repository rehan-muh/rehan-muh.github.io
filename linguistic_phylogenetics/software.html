It covers Bayesian platforms and their extension packages, maximum-likelihood, parsimony and distance programs, network software, tools for summarizing and visualizing trees, tools for preparing linguistic data, and the R and Python libraries most often used alongside them. Software changes quickly: version numbers, package names and web addresses given here were correct at the time of writing, but readers should always check the current documentation and cite the version they actually used. The workflow chapter (Chapter 17) shows how several of these programs fit together in practice.

F.2 Bayesian phylogenetic platforms

F.2.1 BEAST 2

BEAST 2 (Bayesian Evolutionary Analysis Sampling Trees) is a cross-platform Java program for Bayesian phylogenetic inference with an emphasis on time-calibrated trees (Bouckaert et al. 2014, 2019). It is the most widely used program for dated language phylogenies. Its core supports a wide range of substitution models (including binary, covarion and general discrete-state models suitable for cognate data), strict and relaxed clocks, tree priors from the Yule and birth-death families and the coalescent, node calibrations, and flexible priors on all parameters. Models are specified in an XML file, usually created with the graphical program BEAUti; the companion programs LogCombiner, TreeAnnotator and DensiTree combine runs, build summary trees and visualize tree sets. Much of BEAST 2’s power comes from its package system: extensions are installed from within BEAUti through the package manager. The textbook by Drummond and Bouckaert (2015) is the standard introduction. Website: https://www.beast2.org.

F.2.2 BEAST 2 packages relevant to linguistics

BEASTling is not a BEAST 2 package but a standalone Python program that writes BEAST 2 XML files for linguistic analyses from short configuration files (Maurits et al. 2017). It reads data in CSV or CLDF format, links languages to Glottolog, can impose Glottolog subgroups as monophyly constraints, and supports models for lexical (cognate) and typological data, rate variation across features, relaxed clocks and calibrations. Its configuration files make analyses easy to publish and reproduce. However, BEASTling has not been updated since version 1.5.1 (2021). It writes XML for BEAST 2.6, which BEAST 2.7 cannot read without renaming classes to the new beast.base namespace. It also fails to start under Python 3.14, and it needs older versions of clldutils (2.x) and pycldf (below 1.15). Chapter 17 shows a working route. Source: https://github.com/lmaurits/BEASTling.

Babel is a BEAST 2 package developed by Remco Bouckaert specifically for linguistic data. It provides models and tools used in published language phylogenies, including stochastic Dollo-type and pseudo-Dollo covarion models for cognate data, ascertainment-correction schemes suitable for cognate presence/absence data, and utilities for preparing and summarizing linguistic analyses. Source: https://github.com/rbouckaert/Babel.

BEAST_CLASSIC ports to BEAST 2 several models originally developed in BEAST 1, most importantly discrete-trait phylogeography with Bayesian stochastic search variable selection (BSSVS) (Lemey et al. 2009) and continuous-trait diffusion models used in continuous phylogeography. Source: https://github.com/BEAST2-Dev/beast-classic.

GEO_SPHERE implements phylogeographic diffusion on the surface of a sphere and related landscape-aware diffusion models (Bouckaert 2016). Spherical diffusion avoids the distortions of planar diffusion models over large areas, which matters for language families spread across continents. Landscape-aware variants allow diffusion to depend on features such as land and water, an idea first explored for language data in the Indo-European analysis of Bouckaert et al. (2012).

SA (sampled ancestors) implements the fossilized birth-death process with sampled ancestors (Gavryushkina et al. 2014), which allows sampled taxa to lie directly on the lineages leading to other taxa rather than only at the tips. For linguistics, this allows ancient languages such as Latin or Vedic Sanskrit to be modeled as possible direct ancestors of modern languages, the approach taken by Heggarty et al. (2023). Source: https://github.com/CompEvol/sampled-ancestors.

ORC (optimized relaxed clock) provides a reparameterized uncorrelated relaxed clock with improved operators that make relaxed-clock analyses mix much faster (Douglas et al. 2021). Source: https://github.com/jordandouglas/ORC.

bModelTest performs Bayesian site-model averaging, sampling over substitution models and rate-heterogeneity options within the MCMC rather than selecting a single model in advance (Bouckaert and Drummond 2017). It was designed for nucleotide data, but the approach of averaging over models rather than choosing one is relevant to any data type. Source: https://github.com/BEAST2-Dev/bModelTest.

MASCOT implements the marginal approximation of the structured coalescent, a phylogeographic model in which migration between discrete locations is modeled within a population-genetic framework rather than as a trait evolving on a fixed tree (Müller et al. 2018). It has, to our knowledge, rarely if ever been applied to language data (Chapter 11). Source: https://github.com/CompEvol/Mascot.

Model selection packages. The NS package implements nested sampling for estimating marginal likelihoods and their uncertainty (Maturana Russel et al. 2019); the MODEL_SELECTION package implements path sampling and stepping-stone sampling. Both are used to compute Bayes factors between models (Chapter 6).

CoupledMCMC implements Metropolis-coupled MCMC (parallel tempering) with adaptive temperatures for BEAST 2, which can help with multimodal posteriors (Müller and Bouckaert 2020).

BDSKY implements the birth-death skyline model, in which birth and death rates change through time in a piecewise-constant way (Stadler et al. 2013). Developed for epidemiology, it could be used to study changes in the rate of language diversification through time (Chapter 16).

F.2.3 BEAST X and BEAST 1

BEAST 1, whose most widely cited release is BEAST 1.10 (Suchard et al. 2018), is the original BEAST, developed in parallel with BEAST 2 by a partly different team with a strong focus on viral phylodynamics and phylogeography. Its successor, BEAST X, extends the platform with new models and faster inference methods, including Hamiltonian Monte Carlo for many parameters (Baele et al. 2025). BEAST 1 and BEAST X provided the original implementations of discrete phylogeography with BSSVS (Lemey et al. 2009), relaxed random walk continuous phylogeography (Lemey et al. 2010) and phylogeographic generalized linear models with predictors. BEAST 1 and BEAST X files are not compatible with BEAST 2. Website: https://beast.community.

F.2.4 RevBayes

RevBayes (Höhna et al. 2016) is a Bayesian phylogenetics platform built around probabilistic graphical models. Models are written in Rev, an interpreted language resembling R, in which every random variable, deterministic function and constant is declared explicitly. This makes RevBayes the most flexible general-purpose platform: unusual combinations of models, priors and data types can be specified without programming new code. It supports discrete morphological (Mk) models and restriction-site models suitable for cognate data, relaxed clocks, a wide range of tree priors including the fossilized birth-death process, ancestral state reconstruction, stochastic character mapping, and marginal likelihood estimation by path sampling and stepping-stone sampling. The extensive tutorials (https://revbayes.github.io/tutorials/) are among the best learning resources in phylogenetics. The R package RevGadgets visualizes RevBayes output (Tribble et al. 2022). Website: https://revbayes.github.io.

F.2.5 MrBayes

MrBayes (Huelsenbeck and Ronquist 2001; Ronquist, Teslenko, et al. 2012) is a long-established Bayesian phylogenetics program controlled by commands in a NEXUS block. It supports restriction-site (binary) data with ascertainment options such as noabsencesites and variable, standard discrete (morphological) data, covarion models, gamma rate variation, strict and relaxed clocks, node calibrations and tip dating, and Metropolis-coupled MCMC with multiple independent runs and a built-in convergence diagnostic (the average standard deviation of split frequencies). It also estimates marginal likelihoods by stepping-stone sampling. MrBayes is fast and well documented, and is a good choice for undated or simply dated analyses of cognate data. Website: https://nbisweden.github.io/MrBayes/.

F.2.6 TraitLab

TraitLab is a MATLAB package that implements the stochastic Dollo model for binary trait data, in which each cognate class is born once and then may be lost independently on different lineages (Nicholls and Gray 2008). It also handles missing data and catastrophic rate changes on branches (Ryder and Nicholls 2011), and lateral transfer between lineages (Kelly and Nicholls 2017). TraitLab was developed specifically for language data and remains the reference implementation of these models (Chapter 7). It is distributed by its authors; current versions are available through code repositories linked from the publications.

F.2.7 BayesTraits

BayesTraits analyzes the evolution of traits on samples of phylogenetic trees (Pagel et al. 2004; Pagel and Meade 2006). It implements discrete-trait models (including the test of correlated evolution between binary traits of Pagel (1994), with reversible-jump MCMC over model structures), continuous-trait models with Pagel’s \(\lambda\), \(\kappa\) and \(\delta\) transformations, regression, variable-rates models, and ancestral state reconstruction. Because it integrates over a posterior sample of trees, it is a standard tool for comparative studies in linguistics and cultural evolution, including the word-order study of Dunn et al. (2011) (Chapter 13). It is distributed by the Evolution Group at the University of Reading.

F.2.8 Other Bayesian programs

PhyloBayes (Lartillot et al. 2009) implements the CAT family of site-heterogeneous profile mixture models. These models, developed for protein data, let different sites have different equilibrium frequencies. To our knowledge they have rarely if ever been applied to linguistic data, but they are relevant to the question of rate and pattern heterogeneity among meanings (Chapter 7). BAli-Phy (Redelings 2021) jointly estimates sequence alignments and phylogenies; it is a natural model for future work on the joint alignment of word forms (Chapter 16). Website: https://www.bali-phy.org.

F.3 Maximum likelihood

IQ-TREE (Nguyen et al. 2015; Minh, Schmidt, et al. 2020) is a fast and widely used program for maximum-likelihood tree inference. It supports binary (JC2, GTR2) and general discrete morphological (MK) models with ascertainment-bias correction (+ASC), gamma and free-rate heterogeneity, partitioned analyses, automatic model selection with ModelFinder (Kalyaanamoorthy et al. 2017), the ultrafast bootstrap (Hoang et al. 2018), and tests of tree topology. Website: https://iqtree.github.io.

RAxML-NG (Kozlov et al. 2019) is the successor of RAxML, designed for speed and scalability. It supports binary data (BIN) and general multistate data, ascertainment-bias corrections (for example +ASC_LEWIS), and standard and transfer bootstrap support. Source: https://github.com/amkozlov/raxml-ng.

PhyML (Guindon et al. 2010) is a widely used maximum-likelihood program with fast SPR-based tree search and approximate likelihood-ratio tests of branch support.

phangorn (R; Schliep (2011)) provides maximum-likelihood inference for user-defined discrete data including binary cognate data, with ascertainment correction, model comparison and bootstrapping. It is slower than IQ-TREE or RAxML-NG but integrates seamlessly with the rest of the R ecosystem; it is used throughout this book.

F.4 Parsimony and distance methods

PAUP* (Swofford 2003) (Phylogenetic Analysis Using Parsimony, and other methods) is a classic program for parsimony, distance and likelihood analysis, with powerful heuristic tree searches and support for character weighting, constraints and consensus methods. Website: https://paup.phylosolutions.com.

TNT (Tree analysis using New Technology) (Goloboff et al. 2008; Goloboff and Catalano 2016) is the fastest program for parsimony analysis of large datasets, with sophisticated search strategies (ratchet, sectorial searches, tree drifting and fusing) and implied weighting. Website: https://www.lillo.org.ar/phylogeny/tnt/.

PHYLIP (Felsenstein 1989) (Phylogeny Inference Package) is a long-standing collection of programs for distance, parsimony (including Dollo and Camin-Sokal parsimony) and likelihood methods. Its file format, the PHYLIP format, is still widely used for data exchange.

FastME (Lefort et al. 2015) implements balanced minimum-evolution tree construction from distance matrices, with tree rearrangements that improve on neighbor-joining.

phangorn and ape (R) provide UPGMA, neighbor-joining, BIONJ, FastME-style minimum evolution and parsimony (Fitch and Sankoff, with the parsimony ratchet), as illustrated in Chapters 4 and 17.

F.5 Networks

SplitsTree (Huson and Bryant 2006) computes and displays split networks, including NeighborNet (Bryant and Moulton 2004), split decomposition and median networks, together with statistics such as delta scores. It has been the standard tool for exploratory network analysis of language data. Recent versions (SplitsTree 6) have been rewritten with an interactive interface. Source: https://github.com/husonlab/splitstree6.

PhyloNet (Than et al. 2008; Wen et al. 2018) infers explicit phylogenetic networks, in which reticulation nodes represent hybridization or other horizontal events, from gene trees or sequence data, under parsimony, likelihood and Bayesian criteria.

PhyloNetworks (Solís-Lemus et al. 2017) is a Julia package for estimating and analyzing explicit phylogenetic networks, including SNaQ, a pseudolikelihood method that accounts for incomplete lineage sorting (Solı́s-Lemus and Ané 2016). Source: https://github.com/JuliaPhylo/PhyloNetworks.jl.

Gabmap (Nerbonne et al. 2011) is a web application for dialectometry: it computes aggregate distances between dialect sites from transcriptions or categorical data, and visualizes them with maps, clustering and multidimensional scaling. It is useful for dialect continua where tree models are inappropriate.

phangorn (R) implements NeighborNet, consensus networks and delta scores, and plots split networks (Chapter 8).

F.6 Convergence diagnostics, summaries and visualization

Tracer (Rambaut et al. 2018) reads the parameter logs of BEAST, MrBayes and other programs, and displays traces, marginal posterior distributions, effective sample sizes and summary statistics. It is the standard first check on any Bayesian run. Source: https://github.com/beast-dev/tracer.

TreeAnnotator and LogCombiner are distributed with BEAST 2 and BEAST X. LogCombiner combines and resamples log and tree files from several runs, removing burn-in; TreeAnnotator builds a summary tree (maximum clade credibility or other) with node heights and highest posterior density intervals (Heled and Bouckaert 2013).

DensiTree (Bouckaert 2010), distributed with BEAST 2, draws all trees of a posterior sample on top of each other to visualize uncertainty in topology and node heights.

FigTree is a graphical viewer for trees, widely used for displaying annotated BEAST trees. Source: https://github.com/rambaut/figtree.

IcyTree (Vaughan 2017) is a browser-based tree viewer that handles annotated trees and networks without installation. Website: https://icytree.org.

iTOL (Interactive Tree Of Life) (Letunic and Bork 2021) is an online tool for displaying and annotating large trees with associated data. Website: https://itol.embl.de.

SpreaD3 (Bielejec et al. 2016) visualizes phylogeographic reconstructions from BEAST as animated maps.

RWTY (Warren et al. 2017) (R) provides convergence diagnostics specifically for tree topologies, including split-frequency comparisons between runs and visualizations of tree space.

F.7 Tools for linguistic data

LingPy (List et al. 2017; List, Walworth, et al. 2018) is a Python library for quantitative historical linguistics. It provides phonetic alignment (including the SCA method), automated cognate detection (LexStat, SCA-based and edit-distance-based clustering, with Infomap or UPGMA-style partitioning), distance computation, and export to phylogenetic formats. Website: https://lingpy.org; source: https://github.com/lingpy/lingpy.

LingRex extends LingPy with methods for partial cognate detection, correspondence pattern inference and related tasks. Source: https://github.com/lingpy/lingrex.

EDICTOR (List 2017) is a web-based interactive tool for creating, inspecting and editing etymological datasets: aligning word forms, assigning cognate sets (including partial cognates) and inspecting correspondence patterns. It runs in the browser and works with the same TSV formats as LingPy. Website: https://edictor.org.

cldfbench and pylexibank (Forkel and List 2020) are Python packages for creating CLDF datasets reproducibly from raw sources. Each Lexibank dataset is a cldfbench project with a conversion script that downloads or reads the original data, maps concepts to Concepticon and languages to Glottolog, segments transcriptions, and writes validated CLDF. Sources: https://github.com/cldf/cldfbench and https://github.com/lexibank/pylexibank.

pycldf reads, writes and validates CLDF datasets in Python, and provides command-line tools for inspecting them. Source: https://github.com/cldf/pycldf. The CLDF specification itself is documented at https://cldf.clld.org (Forkel et al. 2018).

Other CLDF ecosystem tools. pyglottolog gives programmatic access to the Glottolog data repository (https://github.com/glottolog/pyglottolog); pyconcepticon does the same for Concepticon (https://github.com/concepticon/pyconcepticon); pyclts provides the Cross-Linguistic Transcription Systems reference catalog (https://github.com/cldf-clts/pyclts); and segments tokenizes transcriptions using orthography profiles (https://github.com/cldf/segments).

F.10 Citing software

Software is part of the method. A methods section should name every program and package used, with version numbers, and should cite the publications that describe them, as their authors request. For BEAST 2, the packages used (and their versions) should also be cited, since many of the models in a typical linguistic analysis come from packages rather than from the core. In R, citation("<package>") prints the preferred citation for any installed package, and sessionInfo() records the versions used. Archiving the input files (XML, Rev scripts, NEXUS files with command blocks, BEASTling configuration files) alongside the data allows others to reproduce the analysis exactly (Chapter 17).
